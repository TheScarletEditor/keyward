# Read first

This is one of the Scarlet projects. Before working here, read these in scarlet-hq (the `scarlet-hq` folder next to this one):

1. `ECOSYSTEM.md`: why the Scarlet apps exist, the principles that apply everywhere, and how the owner, the planning chat and Code work together.
2. `NOW.md` and this project's `projects/scarlet-keys/BRIEF.md`: where things stand. `hq-log` updates them at the end of every session.
3. `BACKUP-SPEC.md`: the backup routine. No phase, release or migration here is done until the backups it describes have passed verification, or the owner has explicitly skipped it and the skip is recorded. Run it at the end of every session that changed code, keys or data formats, and before anything hard to undo.

No real personal data in the repo, tests or logs. No em dashes.

## scarlet-hq

Project status, decisions and ideas for every Scarlet Coder project live in scarlet-hq (the `scarlet-hq` folder next to this one). Offer `hq-brief` at the start of a session and run `hq-log` before wrapping up. Only owner-confirmed choices or shipped code count as decisions.
